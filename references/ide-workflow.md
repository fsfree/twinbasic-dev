# twinBASIC IDE 工作流参考

## IDE 面板组成

| 面板 | 用途 |
|------|------|
| **项目资源管理器** | 显示打开项目的文件树 |
| **编辑器** | 主要代码与设计器界面 |
| **属性** | 显示/编辑所选项目的属性 |
| **工具箱** | 列出可放置到窗体上的控件 |

## 调试工具窗口

调试会话期间打开以下窗口：

- **调用堆栈** —— 查看调用链
- **监视** —— 监视表达式值
- **变量** —— 查看局部/全局变量
- **调试控制台** —— `Debug.Print` 输出
- **诊断** —— 诊断信息
- **大纲** —— 代码大纲
- **内存** —— 内存查看

## 设计器

- **tbForm** —— 选择窗体文件时在项目资源管理器中打开的窗体设计器。
- **tbReport** —— 选择报表文件时打开的报表设计器。

## 加载项

- 第三方与社区加载项通过附加命令与工具窗口扩展 IDE。
- 安装第三方加载项参见 IDE「Add Ins」章节。
- 自行开发加载项使用 **tbIDE** 包（加载项 SDK）。

## 项目配置

twinBASIC 提供多种项目类型与配置选项：

- 项目类型：标准 DLL、控制台应用程序、Windows 服务、内核驱动等。
- 编译器选项：优化与安全选项。
- 入口点覆盖与 IAT 放置。
- ActiveX 项目的注册选项。

## 典型工作流

1. **创建项目** —— 通过 IDE 新建，选择项目类型与目标平台（32/64 位）。
2. **编写代码** —— 在编辑器中编写 `.bas` / `.cls` / `.frm` 源码，或通过 tbForm 设计器设计界面。
3. **配置项目** —— 设置编译器选项、入口点、ActiveX 注册等。
4. **编译** —— 选择目标平台编译为 EXE / DLL。
5. **调试** —— 设断点、单步执行，用监视/变量/调试控制台定位问题。
6. **发布** —— 生成发行版；如需共享代码，可打包为 TWINPACK 并发布到 TWINSERV。

## 编译器与 IDE 增强

- 编译器警告与严格模式。
- 调试跟踪记录器、过期指针检测。
- 用于直接运行 Sub 的 CodeLens。
- 现代 IDE：主题、代码折叠等。
